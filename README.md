# QR Suite

A beautiful, fully offline Progressive Web App for generating, scanning, and managing QR codes.

Create stylish QR codes with custom colors, error correction, and artistic options — or scan any QR code using your camera or uploaded image. Everything works offline once installed.

![QR Suite Preview](https://raw.githubusercontent.com/SnazzyGaz/QRsuite/main/hm.png)

## ✨ Features

- **Generate QR Codes** — Enter text, URLs, or any data
- **Highly Customizable**:
  - Error correction levels
  - Output size
  - Art styles
  - Custom finder rings
  - Module & background colors
- **Scan QR Codes** — Use camera, upload image, or drag & drop (supports png, jpg, gif, webp)
- **Save & Manage** — Keep a history of generated and scanned codes
- **Fully Offline** — Installable PWA that works without internet
- **Mobile-First** — Excellent experience on phones, tablets, and desktop

## 📱 Install as App

**On Android / Desktop (Chrome/Edge):**
1. Open the site
2. Click the install icon in the address bar (or three-dot menu → Install app)

**On iPhone / iPad (Safari):**
1. Open the site
2. Tap the Share button
3. Select "Add to Home Screen"

## 🛠️ Tech Stack

- Pure HTML, CSS & JavaScript (no heavy frameworks)
- [QR Code](https://github.com/davidshimjs/qrcodejs) generation
- WebRTC / getUserMedia for camera scanning
- Service Worker for offline caching
- Web App Manifest for PWA support
